# FT8CN 原快速解码召回率全面分析

测试对象：`stability-only` 分支（解码链与 `63e9d229` 完全一致）的“快速解码”挡位。

## 1. 测试条件与统计口径

| 项目 | 内容 |
| --- | --- |
| 测试集 | 60 个 15 秒 wav，1298 条参考报文（`ft8_w` 基准集） |
| 参考频率范围 | 265 ~ 2830 Hz |
| 解码挡位 | 快速解码（单遍，不做 SID/减法） |
| 取数设备 | 模拟器 `emulator-5554`；召回率是确定性的，真机同一份数据得到完全相同的 940 条命中 |
| 耗时数据 | 真机 vivo V2338A（骁龙 8 Gen 3）两次实测：65.7 ms、62.7 ms |
| 匹配口径 | 与 `BenchmarkActivity` 一致：报文转大写、按空白切分、取前 3 个 token；`<...>` 哈希呼号统一为 `<...>` |
| 参考重复行 | 保留，不去重（同一报文在同一时隙出现两次，命中一次即算两条命中） |

原始数据：

- `docs/analysis/data/decoded_fast.tsv`：本次快速解码的全部输出（文件、报文、SNR、dt、频率）
- `docs/analysis/data/bench_fast.txt`：基准汇总
- `docs/analysis/analyze_fast_recall.py`：本报告的全部统计脚本，可复现

## 4. 综合分析

1. **瓶颈是频率重叠，不是灵敏度。**
   - 干净信号（最近邻 ≥50 Hz）召回 **91.4%**；
   - 重叠信号（<50 Hz）召回 **50.3%**；
   - 83.2% 的漏解来自重叠。
2. **强信号同样会漏。**
   - 64 条 SNR ≥0 dB 的报文漏解，其中 60 条最近邻 <50 Hz；
   - 11 条 SNR ≥10 dB 的漏解，**全部**是邻道重叠；
   - 说明单纯加迭代次数或放松门限收益有限，必须处理同频/邻频干扰。
3. **频率段差异由密度决定。**
   - 500~1500 Hz 召回 65~70%，两端 80% 左右；
   - 该区间参考报文占比 44.4%，是信号最密的地方。
4. **时隙负载越高越差。**
   - 每时隙 31 条以上时召回降到 60.0%；
   - 每时隙 11~20 条时 79.0%。
5. **时间偏移不是主因。** 各 dt 区间 65~76%，无单调趋势。
6. **报文类型差异可由 SNR 解释。** 网格报文召回最低，同时平均 SNR 最低。
7. **每时隙波动大。** 标准差 14.5 个百分点，P10 61.3%、P90 86.4%，说明表现高度依赖该时隙的频道拥挤程度。
8. **多余消息 3.9%，平均 SNR -11.6 dB。** 未做 JTDX 验证，实际误报率应低于此值。

## 5. 优化建议（按预期收益排序）

| 优先级 | 方向 | 依据 | 预期 |
| --- | --- | --- | --- |
| 高 | 快速挡位增加一轮“解码后减法”（SIC/`ReBuildSignal`） | 重叠占漏解 83.2% | 直接针对最大失分项 |
| 高 | 邻道 <50 Hz 时优先保证强信号先解、再减掉重构信号 | 11 条 ≥10 dB 漏解全部重叠 | 强信号不再被弱邻道拖累 |
| 中 | 500~1500 Hz 提高候选数上限/细分搜索 | 该区间召回低 10~15 个百分点 | 缓解密集区候选截断 |
| 中 | 按时隙负载动态调整候选数与超时 | >31 条时掉到 60% | 拥挤时隙收益明显 |
| 低 | 调整时间偏移搜索范围 | dt 各区间差异小 | 收益有限 |
| — | 增加迭代次数/放松门限 | 干净信号已 91.4%，且强信号漏解与 SNR 无关 | 收益有限 |

## 6. 复现方式

```powershell
# 1. 取数（基准版 APK，fast 挡位）
adb shell am start -n com.bg7yoz.ft8cn/.ft8listener.BenchmarkActivity `
  --es dir /sdcard/Android/data/com.bg7yoz.ft8cn/files/ft8test --es modes fast

# 2. 拉取结果
adb pull /sdcard/Android/data/com.bg7yoz.ft8cn/files/decoded_fast.tsv
adb pull /sdcard/Android/data/com.bg7yoz.ft8cn/files/ft8test

# 3. 生成统计
python docs/analysis/analyze_fast_recall.py decoded_fast.tsv ft8test report.md
```
