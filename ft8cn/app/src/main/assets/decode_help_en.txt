Decode mode:
Fast decode: Default mode, one decoding pass on received audio.
Deep decode: Recursive decoding that process received audio in multiple passes.
wsjtx Normal: Decode one pass with the WSJT-X algorithm library (mfsk-core).
wsjtx Deep: Same as wsjtx Normal, but enables the full LLR/BP/OSD fallback and a looser acceptance threshold; more weak signals, longer decoding.
wsjtx Normal multi-core: Split 100-3000 Hz into bands (100 Hz overlap) and decode them in parallel on multiple CPU cores, then merge and deduplicate.
wsjtx Deep multi-core: wsjtx Deep parameters plus spectrum-band parallelism.
* Note: Deep decoding and wsjtx Deep require longer decoding time and more battery consumption.
* Note: every band performs its own whole-slot FFT, so more bands is not always faster; the band count defaults to the CPU core count, capped at 8.
* Note: wsjtx modes require arm64-v8a or x86_64 devices; other devices fall back to the original decoder automatically.
